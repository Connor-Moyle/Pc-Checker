# Design mockups

The images in this folder are **design mockups**, not screenshots. They were
rendered from HTML to show the intended layout, grouping and tone of each
page before and during development. Every image carries a "Design mockup"
caption so it cannot be mistaken for the real application.

| File | Page |
|---|---|
| `contact-sheet.png` | All twelve mockups on one sheet |
| `dashboard.png` | Dashboard |
| `temperatures.png` | Temperatures |
| `overlay.png` | In-game overlay over a sample game frame |
| `hardware.png` | Hardware |
| `health.png` | Health |
| `storage.png` | Storage |
| `fans.png` | Fans |
| `lighting.png` | Lighting |
| `drivers.png` | Drivers |
| `latency.png` | Latency |
| `overclock.png` | Overclock |
| `settings.png` | Settings |

Real screenshots are captured by CI from demo mode on a Windows runner and
committed into [`docs/screenshots/`](../screenshots/README.md). Where the
shipped app and a mockup differ, the app is right and the mockup is history.
